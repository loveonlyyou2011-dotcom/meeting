====================================================
 회의록 자동 생성 프로그램 - 환경설정 가이드
====================================================

이 프로그램을 다른 컴퓨터에서 실행하려면 아래 순서대로 진행하세요.
(zip 압축 파일에는 소스 코드만 들어있고, 아래 설치/설정은 옮긴 컴퓨터에서
 별도로 한 번씩 해주셔야 합니다.)


----------------------------------------------------
1단계. Python 설치 확인
----------------------------------------------------
- Python 3.12 버전이 설치되어 있어야 합니다.
- 설치 여부 확인: 명령 프롬프트(또는 PowerShell)에서
    python --version
  실행 후 3.12.x 가 나오면 정상입니다.
- 없다면 https://www.python.org/downloads/ 에서 설치하세요.
  (설치 시 "Add python.exe to PATH" 체크박스를 꼭 체크하세요.)


----------------------------------------------------
2단계. ffmpeg 설치
----------------------------------------------------
- 오디오 파일을 합치고 변환하는 데 필요합니다.
- PowerShell에서 아래 명령 실행:
    winget install Gyan.FFmpeg
- 설치 후에는 반드시 "새 터미널 창"을 열어야 ffmpeg 명령이 인식됩니다
  (설치 직후 같은 창에서는 PATH가 바로 반영되지 않을 수 있습니다).


----------------------------------------------------
3단계. .env 파일 만들기 (가장 중요)
----------------------------------------------------
압축 푼 폴더(meeting-minutes) 안에 있는 ".env.example" 파일을
복사해서 파일 이름을 ".env" 로 바꾸세요.
(윈도우 탐색기에서 확장자가 안 보이면, 보기 > 파일 확장명 체크)

.env 파일을 메모장으로 열면 아래처럼 되어 있습니다:

    GEMINI_API_KEY=
    HF_TOKEN=

이 두 줄의 "=" 뒤에 아래 방법으로 발급받은 값을 붙여넣으면 됩니다.
(줄바꿈 없이, = 바로 뒤에 붙여넣기)


--- 3-1. GEMINI_API_KEY 발급 방법 ---

1) https://aistudio.google.com/apikey 접속 (구글 계정으로 로그인)
2) "Create API key" 버튼 클릭
3) 생성된 키(AIza로 시작하는 긴 문자열) 복사
4) .env 파일의 GEMINI_API_KEY= 뒤에 붙여넣기
   예) GEMINI_API_KEY=AIzaSyD1234567890abcdefg...

* 무료로 발급 가능하며 신용카드 등록이 필요 없습니다.
* 절대 이 키를 다른 사람에게 공유하거나 인터넷(GitHub 등)에 올리지 마세요.


--- 3-2. HF_TOKEN 발급 방법 (Hugging Face) ---

화자분리(누가 말했는지 구분)에 사용하는 AI 모델을 받아오기 위해 필요합니다.
아래 3가지를 순서대로 해야 합니다 (하나라도 빠지면 화자분리가 작동하지 않습니다).

1) https://huggingface.co 에서 회원가입 및 로그인 (무료)

2) 아래 두 페이지에 각각 접속해서 로그인한 상태로
   "Agree and access repository" 버튼을 눌러 라이선스에 동의하세요.
   - https://huggingface.co/pyannote/speaker-diarization-3.1
   - https://huggingface.co/pyannote/segmentation-3.0
   (둘 다 해야 합니다. 하나만 동의하면 에러가 납니다.)

3) https://huggingface.co/settings/tokens 접속
   - "Create new token" 클릭
   - 이름은 아무거나 입력 (예: meeting-app)
   - 권한(Type)은 "Read" 선택
   - "Generate a token" 클릭 후 생성된 토큰(hf_로 시작) 복사

4) .env 파일의 HF_TOKEN= 뒤에 붙여넣기
   예) HF_TOKEN=hf_AbCdEfGhIjKlMnOpQrStUvWxYz1234567

* 이 토큰도 마찬가지로 외부에 노출되지 않도록 주의하세요.
* 만약 실수로 GitHub 등 외부에 노출되면 Hugging Face가 자동으로 감지해서
  토큰을 강제로 만료시킵니다 - 그럴 경우 3)번부터 다시 발급받으면 됩니다.


----------------------------------------------------
4단계. 패키지 설치
----------------------------------------------------
PowerShell에서:
    cd 압축_푼_폴더\backend
    pip install -r requirements.txt

- 용량이 커서(약 2GB) 시간이 꽤 걸릴 수 있습니다.
- 이미 requirements.txt에 서로 호환되는 버전이 정확히 고정되어 있으므로
  추가로 버전을 바꾸실 필요는 없습니다.


----------------------------------------------------
5단계. 실행
----------------------------------------------------
    uvicorn main:app --reload

정상 실행되면 아래와 같은 메시지가 뜹니다:
    Uvicorn running on http://127.0.0.1:8000

브라우저에서 http://localhost:8000 접속 후 마이크 권한을 허용하면
바로 사용할 수 있습니다.


----------------------------------------------------
참고
----------------------------------------------------
- .env 파일은 각 컴퓨터마다 따로 만들어야 합니다 (zip에는 포함되어 있지
  않습니다 - 키가 유출되지 않도록 일부러 뺐습니다).
- 같은 본인 계정의 API 키를 여러 컴퓨터에서 동시에 써도 문제는 없습니다.
- data 폴더(회의 녹음/기록)도 zip에는 빠져 있어서, 새 컴퓨터에서는
  회의 기록이 빈 상태로 시작합니다.
